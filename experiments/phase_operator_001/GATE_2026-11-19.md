# PHASE-OPERATOR-001 — CPU mechanism gate (2026-11-19)

**Decision: REVISE / PAUSE SCALING.** This is a negative, bounded synthetic experiment. It does **not** establish a neural-language-model benefit, a parameter-compression result, GPU performance, formal certification, or production readiness.

## Hypothesis
Can a trainable phase-conditioned orthogonal operator family outperform ordinary low-rank and context-gated updates, without dense per-token weight materialization?

### Phase-generated teacher experiment
Width 32, rank 4, teacher-controller scale 0.30, AdamW LR 0.003, 150 steps, seeds 42, 43, 44. Evaluation uses fresh held-out synthetic inputs and contexts; +2 shifted context for OOD. The reported normalized MSE is relative to a zero-output baseline (1 = zero baseline; lower better). Methods have **different trainable scalar counts**.

| Method | Trainable scalars | ID normalized MSE mean | Shifted mean |
|---|---:|---:|---:|
| LoRA | 256 | **0.1735** | **0.3903** |
| Phase | 517 | 0.8100 | 0.8399 |
| Real-gate | 389 | 0.9045 | 0.9037 |
| Spectral-static | 389 | 0.8847 | 0.9140 |
| Fourier-static | 8 | 0.9951 | 0.9979 |

Phase did **not** beat LoRA despite the teacher being phase-structured. This specifically blocks scaling, not the analytical operator bounds.

### Mathematical diagnosis
For isotropic independent Gaussian `x,z` and phase controller `theta=b+Cz`, the optimal static operator’s relative irreducible residual energy in the teacher’s known bases is
`1 - (1/r) * sum_j exp(-||C_j||_2^2)`.
With scale 0.30 it is ~0.083–0.101 across the three teachers. Thus the original teacher was mostly static.

At scale 1.50, seed 42 has irreducible dynamic fraction ~0.895, but phase ID error was 0.962 versus LoRA 0.946 at 150 steps. A diagnostic that supplies the **teacher's exact bases** and matches initial gain improved phase ID error to 0.549; with randomly initialized bases and matched gain it was 1.482. At scale 0.30, those values were 0.143 and 0.897. The oracle basis is not deployable and cannot be used as a benchmark score. Strong-phase oracle shifted-context error remains 1.343.

**Interpretation:** jointly discovering the operator frame and its phase controller is an optimization/identifiability obstacle; static adaptation can capture most of a weak-phase teacher. No evidence presently warrants scaling.

## Next bounded action
Test a **two-stage anchored phase adapter**: first identify useful subspaces using an ordinary low-rank fit, then modulate within the identified subspaces; benchmark against *matched-parameter real-gated LoRA*. Instrument phase variance, principal angles, QR cost, and input-context Jacobian. If phase cannot outperform simple baselines on a genuinely dynamic held-out teacher, retire the phase mechanism before HF/large-model work.
